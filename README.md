# Overview

I've been wanting to try my hand at building Android apps for a few years, and Kotlin is where I'm starting.
This "Hello World" project is a quick confirmation of understanding after completing the Kotlin Beginner Tutorial (linked below).

This program highlights the use of functions, lambda functions, classes and data classes.
The Main function calls a function, runN, passing it an interger and a lambda function (which just calls println("Hello World") in this case).
It then creates an instance of the class Envelope and prints the address (a data class) from the envelope.
